# WordPress ↔ preview parity — приёмочные замечания

Status: ready-for-agent

Tracker: `docs/work/specs/`, `docs/work/tickets/` (локальный markdown; `setup-engineering-workflow` в репо не запускался — при желании можно прописать `docs/agents/issue-tracker.md`).

Product locks: `docs/DECISIONS.md`. Glossary: `docs/CONTEXT.md`. Источник поведения UI — honest `preview/` (не `preview-filled/` как официальный текст).

## Problem

Локальный WordPress-контур после cutover polish всё ещё расходится с preview и с приёмкой по chrome, IA внутренних витрин, контрасту night/BVI и карточной вёрстке каталогов. Приёмщик видит «чужой» header/menu, дубли страниц, низкий контраст в night, нерабочую версию для слабовидящих и тексты-заглушки вместо плиток как в preview.

## Solution

Довести WP child-тему + сид контента до паритета с preview по перечисленным замечаниям: единый chrome (кнопки, mobile «+», подменю), обновлённая IA (слияние дублей, одна страница контактов), карточные витрины (структура, лаборатория, каталоги, документы, учёный совет, профсоюз/СМУ), контраст night + рабочий BVI, veil→stagger появления, тема day/night/**auto по времени суток**, фото-слоты без жёсткой обрезки.

Где замечание **меняет** прежний lock в DECISIONS — в Notes; после закрытия тикетов обновить DECISIONS одним блоком.

## User stories

1. As посетитель, I want кнопки шапки одного размера/скругления и корректное mobile-меню (гамбургер только в узком окне; дерево через «+» как в preview), so that chrome не выглядит сломанным.
2. As посетитель, I want в десктоп-подменю стрелки у пунктов с детьми, другой оттенок панели и тонкие горизонтальные разделители как в preview, so that вложенность читается.
3. As посетитель, I want на главной «28 лет институту» без указателя «с какого года» и без фразы про «4 языковые структуры», so that ввод официальный и короткий.
4. As посетитель, I want контрастный подвал без строки «Ресурсы Академии и государственные порталы», so that блок ссылок не выглядит как лишний заголовок.
5. As посетитель, I want тему day / night / **auto** (по местному времени суток), so that переключатель учитывает время пользователя.
6. As посетитель «Об институте», I want фото в окнах целиком (object-fit contain) с заполнителем фона в пустых полях, so that нестандартный кадр не обрезается.
7. As посетитель, I want veil открытия страницы, затем staggered появление блоков как в preview, so that motion полный, а не только завеса.
8. As посетитель night на Руководстве / Структуре / лабораториях, I want контрастные заголовки и ячейки, so that текст читается.
9. As посетитель Руководства, I want только сетку карточек сотрудников (без вводного текста «сотрудник…»), with photo-slot градиентом как в preview при отсутствии фото.
10. As посетитель Структуры, I want плитки подразделений со ссылками (мелким шрифтом — руководитель), без маркерного списка и без лишнего текста; «Отдел физико-химии тонкопленочных материалов» визуально под одной чертой с родственной единицей; crumbs как в preview.
11. As посетитель, I want одну страницу «Об институте» без отдельной кнопки «Сведения» на ту же по смыслу витрину, so that нет дубля.
12. As посетитель лаборатории, I want крупное главное фото коллектива и плитки направлений / проектов / завершённых проектов с руководителем как в preview.
13. As посетитель BVI, I want рабочую версию для слабовидящих (кнопка не гигантская; режим реально включается), so that доступность v1 выполняется.
14. As посетитель админ/общественных единиц, I want без ссылки «Ко всем подразделениям»; профсоюз и СМУ — секции как пакет лаборатории (руководство, документы, контакты).
15. As посетитель «Направления работы» и «Разработки», I want карточки, собранные с лабораторий, so that институтские каталоги не пустые и не расходятся с пакетами.
16. As посетитель Сотрудничества, I want строку «город, страна» внутри плитки, so that текст не вылезает.
17. As посетитель Публикаций, I want без вводного абзаца; список + боковой блок статистики; группировка/якоря по годам (в т.ч. при дозаписи старых лет).
18. As посетитель Учёного совета / Матбазы / Документов / Новостей, I want плитки и секции без дублирующего текста; в Документах — плитка на реквизиты; Новости без ленты-оглавления в начале.
19. As посетитель Контактов, I want одну страницу: карта/адрес + обратная связь + реквизиты (бывшие подпункты меню сворачиваются в якоря или убираются из меню).

## Implementation decisions

### Chrome и меню

- Выровнять tool-кнопки шапки (высота, padding, `border-radius`); BVI — компактный control, не доминирует над языком/темой.
- Гамбургер: только в breakpoint mobile; на wide не занимать место language switcher (fix CSS/`display` / order).
- Desktop dropdown: chevron/caret у пунктов с детьми; фон submenu — отличающийся оттенок; `border`/`hr`-разделители между рядами как в preview.
- Mobile overlay: дерево не «всё раскрыто»; expand через «+» / «−» как в preview JS.

### Главная и подвал

- Убрать копи про «4 языковые структуры».
- Оставить «28 лет институту»; убрать указатель года основания / «с YYYY».
- Footer: удалить заголовок «Ресурсы Академии и государственные порталы»; сам NAS-pack ссылок оставить; усилить контраст поверхности footer относительно body (токены day/night).

### Тема и motion

- Режим темы: `day` | `night` | `auto`. `auto` = по локальным часам пользователя (пороги зафиксировать в реализации, напр. night ~22:00–07:00 или по `prefers-color-scheme` **плюс** clock — выбрать clock-based как просит приёмка). Persisted preference; auto пересчитывать при load и смене часа.
- Veil: сначала page-open veil, затем staggered enter дочерних блоков (как preview); off в BVI и `prefers-reduced-motion`.

### Фото и карточки людей

- About (и аналогичные «окна»): `object-fit: contain`; фон слота — нейтральный/градиентный placeholder в пустых полях.
- Нет фото сотрудника: градиентный photo-slot как в preview (не плоская серая плашка).
- Руководство: убрать prose перед сеткой; только карточки в два столбца (+ crumbs).

### Структура и crumbs

- Страница Структура: только плитки подразделений (labs → admin → union/SMU порядок как lock); в плитке title + optional head name мелким шрифтом; без bullet-list.
- Объединить визуально «Отдел физико-химии тонкопленочных материалов» под одну черту с согласованной соседней единицей (одна карточка-группа или общий заголовок секции — без потери ссылок).
- Crumbs на внутренних страницах ветки «Об институте» и далее: `Главная / … / текущая` как в preview (в т.ч. Руководство, Структура).

### IA merges (обновляют DECISIONS)

- **Об институте** и **Сведения** → одна витринная страница; пункт «Сведения» убрать из меню (или редирект на about).
- **Контакты** + **Обратная связь** + **Реквизиты** → одна страница с якорями `#feedback`, `#requisites` (меню Контакты без детей или дети = якоря).
- Документы: убрать вводный текст и комментарии про реквизиты; плитки файлов; плитка «Реквизиты» ведёт на контакты `#requisites`.
- Новости: убрать вводный абзац и текстовое оглавление/датамп перед карточками ленты.

### Лаборатории, каталоги, сообщества

- Lab hero photo крупнее (коллектив).
- Направления / действующие проекты / завершённые — плитки с атрибуцией руководителя (как preview lab pack).
- Институтские **Направления работы** и **Разработки**: агрегация с lab packs (уже lock; проверить сид/рендер, что карточки реально подтягиваются).
- Админ-единицы (кадры, инженер, охрана труда, бухгалтерия) и ранее профсоюз/СМУ: убрать «Ко всем подразделениям».
- Профсоюз и СМУ: секции руководство / документы / контакты по смыслу lab pack.

### Прочее контент

- Сотрудничество: clamp/truncate «город, страна» внутри плитки.
- Публикации: без lead prose; список + **боковой** блок статистики; группировка по году (заголовки/якоря года; при вставке старой записи год-секция появляется или запись встаёт в существующую).
- Учёный совет: блоки «состав», «положение», «контакты» (плитки/секции).
- Матбаза: плитки без дублирующего текста перед сеткой.
- Night contrast pass: Руководство, Структура, lab pages (и заголовки, и ячейки).
- BVI: починить активацию (плагин/класс IBOCH); кнопка в шапке компактная.

### Стек

Без смены: WordPress + `ichnm-kadence` + `ichnm-site` + Polylang. Правки preview при необходимости как эталон, затем паритет WP. Сид bump после IA merges.

## Testing decisions (seams)

Предлагаемые швы (подтвердить или поправить перед реализацией):

1. **Theme preference** — `get/set` режима `day|night|auto` + вычисление effective theme от clock; unit без DOM; JS smoke: auto меняет class на `html`.
2. **Menu tree / IA redirects** — site model: about↔overview merge, contacts children → anchors; тест модели/меню: нет отдельных page id для удалённых дублей; редиректы 301/сид.
3. **Catalogue aggregation** — уже существующий roster/catalogue seam: lab directions/developments → institute pages; тест: N lab items → N cards with lab attribution.
4. **Publications by year** — группировка списка публикаций по году + stats sidebar counts; unit на чистой функции группировки.
5. **BVI enable** — контракт: клик tool → document/html class или API плагина активен; smoke на WP.

Не шов: пиксельные отступы chevron; точные пороги часов auto (константа в тикете).

Smoke: header wide+narrow, dropdowns, about/leadership/structure/lab/science/developments/cooperation/publications/council/facilities/documents/news/contacts, night + BVI + veil stagger, footer без лишнего heading.
