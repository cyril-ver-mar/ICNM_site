## Problem

Официальный сайт ИХНМ на `ichnm.by` устарел (Java, студия Forever) и не выглядит институтом НАН. Нужна официальная замена: вид и информационная архитектура как у ИБОХ, свои разделы ИХНМ, идентификационный блок НАН, четыре языковых префикса. Пакет к переключению (векторы, PDF, списки публикаций, составы лабораторий, тексты профсоюза и СМУ) и PHP-тариф придут позже — каркас нельзя на них блокировать.

## Solution

WordPress + Kadence. Модель сайта (меню, ленты, роли, подвал, главная) — один глубокий модуль; WordPress-плагин и дочерняя тема Kadence — адаптеры. v1 публично только по-русски; `/en/`, `/be/`, `/zh/` сразу есть как заглушки. Тестовый контур локально (и позже на PHP-тарифе). Переключение домена — отдельный шаг после приёмки. Пока нет исходников коллег: плейсхолдеры, без пустых иконок соцсетей ИХНМ.

## User stories

1. As руководство НАН / официальный гость, I want увидеть идентификационный блок НАН, полное имя ИХНМ и стабильные юридические и государственные ссылки, so that сайт читается как институт Академии, а не как чужой портал.
2. As научный партнёр, I want найти структуру, научную деятельность, разработки, материальную базу и сотрудничество, so that понятно, с кем и о чём договариваться.
3. As сотрудник-редактор, I want из админки публиковать новости, мероприятия, объявления и «СМИ о нас» и не иметь прав ломать шапку, подвал и витринные страницы, so that лента живая, а официальная оболочка цела.
4. As разработчик от института, I want поднять тестовый контур без PHP-тарифа и без пакета к переключению, so that вёрстка и типы записей проверяются до прихода файлов коллег.
5. As посетитель с другого языка, I want переключалку и префиксы `/en/`, `/be/`, `/zh/`, so that адреса не придётся ломать, когда появятся переводы.
6. As аспирант / соискатель, I want блок образование (аспирантура, докторантура, совет по защитам, стажировки и курсы) и вакансии, so that кадровые пути видны, даже если часть текстов ещё плейсхолдер.
7. As сотрудник лаборатории, I want страницу подразделения с вкладкой сотрудников (избранные публикации, научные метрики) без личных мини-сайтов, so that люди привязаны к лаборатории.
8. As участник AIST, I want раздел конференции на этом сайте с базовой справкой, so that регистрация пока может оставаться на `aist.ichnm.by`.

## Implementation decisions

- CMS и тема: WordPress + Kadence (ADR 0001, 0002). Не Java Forever, не отдельная кастомная тема.
- Модель сайта — источник правды для меню, языковых префиксов, главной, подвала, типов лент, вкладки сотрудников и ролей. Плагин регистрирует типы записей и роль редактора лент по этой модели.
- Дочерняя тема Kadence: идентификационный блок НАН, переключалка языков, подвал (стабильный пакет + соцсети НАН; соцсети ИХНМ только если URL есть), кнопка версии для слабовидящих.
- Главная: короткий официальный ввод, новости, входы в структуру и разработки, ближайшее мероприятие. Нет промо 3D-печати.
- Типы лент: новость, мероприятие, объявление, СМИ о нас, публикация. Подразделение — страница/тип с вкладкой сотрудников. Витринные страницы — обычные страницы WordPress.
- AIST — витринная страница, базовая справка + заглушка.
- Документы (устав, антикоррупция, электронные обращения, реквизиты) — страницы-плейсхолдеры, пока нет PDF.
- Локальный тестовый контур (Docker) в этом срезе. PHP-тариф и переключение домена — позже.
- Тексты с текущего ichnm.by переносятся близко к оригиналу. В превью уже: главная (новости, AIST), об институте, наука, сотрудничество, контакты, руководство, структура (лаборатории), разработки (включая 3D), профсоюз.

## Testing decisions (seams)

Согласованный шов: **модель сайта** (модуль core). Публичный интерфейс: загрузить модель; отдать меню, языки, блоки главной, юридические и государственные ссылки, типы лент, поля научных метрик, что может публиковать редактор, что является витринной страницей, что запрещено на главной.

- Тесты (pytest) цепляются только к этому интерфейсу. Известные инварианты из `docs/DECISIONS.md`, не снимок HTML.
- Адаптер: WordPress-плагин и дочерняя тема. Второй адаптер не пишем «на вырост».
- Не шов этого среза: визуал Kadence, живой DNS, PDF коллег, браузерный клик по админке.
- Streamlit / `src/services` в этом репозитории нет.

## Out of scope

- Заказ PHP-тарифа, DNS, переключение домена, веб-почта с боевым URL
- Векторы логотипов, PDF документов, стартовый список публикаций, составы лабораторий, тексты профсоюза и СМУ — закинем потом
- Заполнение `/en/`, `/be/`, `/zh/`
- Регистрация AIST, архив конференций как отдельный продукт
- Персональные страницы сотрудников
- Агрегация новостей НАН
- Пиксельный клон ИБОХ, Bitrix, статическая вёрстка без WordPress

## Notes

- Главная аудитория: руководство НАН и научные партнёры; промышленность, кадры и сотрудники — вторичны.
- Иконки соцсетей ИХНМ не рисуем пустыми.
- Приёмка института обязательна до переключения; старый сайт до тех пор жив.
