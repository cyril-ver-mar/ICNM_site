# СМИ об ИХНМ и открытые сведения о руководстве

## Answer

Внешние публикации об Институте есть: «Советская Белоруссия» / sb.by, портал «Нефтехимия» (belchemoil.by), БелТА, портал НАН, журнал «Наука и инновации». Академическая газета «Навука» несколько раз писала об ИХНМ (онлайн-версии выпусков на gazeta-navuka.by, с номером газеты в шапке материала).

Научное руководство на текущем ichnm.by: директор А. А. Рогачёв, заместители Ж. В. Игнатович и А. В. Зураев, почётный директор академик В. Е. Агабеков. Отдельные страницы сделаны только для этой четвёрки (официальный раздел «Руководство», не персональные сайты сотрудников лабораторий). Фото на сайт институт ещё не передал.
