# Как открыть сайт ИХНМ

Два контура. **Превью** открывается сразу в браузере, без Docker и без хостинга. **WordPress** — полный тестовый контур, как будет на PHP-тарифе.

Тексты коллег (логотипы, PDF, публикации, составы лабораторий) не нужны: везде плейсхолдеры.

Рабочая папка: `ICNM_site` (в Cursor это корень проекта).

---

## 1. Превью (так смотреть сейчас)

В терминале из корня проекта:

```bash
chmod +x scripts/open-site.sh scripts/build_preview.py
./scripts/open-site.sh
```

Скрипт соберёт HTML и откроет главную в браузере по умолчанию.

Если окно не открылось — дважды щёлкните файл:

`preview/index.html`

Либо перетащите его в Chrome / Safari / Firefox.

### Что должно быть на экране

- тёмная шапка с полным именем института и ссылкой на [nasb.gov.by](https://nasb.gov.by/rus/index.php)
- переключалка **RU EN BE ZH** (структура сайта на всех языках; тексты института пока по-русски)
- меню разделов (Об институте, Структура, Разработки, …)
- главная: короткий ввод, новости, структура, разработки, ближайшее мероприятие — **без** блока 3D-печати
- подвал: Президент, Совмин, pravo.by, «Навука», профсоюз НАН, портал НАН, соцсети НАН

Внутренние страницы — плейсхолдеры. AIST: справка и ссылка на [aist.ichnm.by](http://aist.ichnm.by/). Структура: пример вкладки сотрудников.

Пересобрать превью после правок модели:

```bash
.venv/bin/python scripts/build_preview.py
```

Скрипт пишет два дерева:

| Папка | Что смотреть |
|-------|----------------|
| `preview/` | Честный контур: пустые слоты фото и «Файл не загружен» |
| `preview-filled/` | Макет с рыбой: ФИО/приборы/статьи лабораторий на буквы А–Д, картинки-заглушки |

Наполненный макет: `preview-filled/index.html` (или `open preview-filled/index.html`). Это не официальные сведения.

## 2. WordPress на этой машине (когда нужен как на проде)

Нужен **Docker Desktop** для Mac: https://www.docker.com/products/docker-desktop/  
Установите, откройте приложение один раз (кит должен стать зелёным), затем:

```bash
chmod +x scripts/local-setup.sh
./scripts/local-setup.sh
```

| Что | Адрес |
|-----|--------|
| Сайт | http://localhost:8080 |
| Админка | http://localhost:8080/wp-admin |

Вход при первой установке: логин `admin`, пароль `admin`. **Сразу смените пароль** в «Пользователи». Этот пароль нельзя тащить на хостинг ichnm.by.

Скрипт ставит тему Kadence, дочернюю «ИХНМ Kadence», плагин «ИХНМ — модель сайта», Polylang и кнопку для слабовидящих.

Остановить:

```bash
docker compose down
```

Снова включить (без переустановки):

```bash
docker compose up -d
```

### Smoke и бэкап (перед test URL / handoff)

```bash
chmod +x scripts/wp-smoke.sh scripts/wp-backup.sh
./scripts/wp-smoke.sh          # HTTP 200 по обязательным путям
./scripts/wp-backup.sh         # снимок → exports/wp-backup-… (не в git)
```

Полный чеклист (в т.ч. ручная приёмка): `docs/work/smoke-checklist.md`.  
Хостинг / volumes / Polylang / seed: `docs/work/2026-09-02-hosting-handoff.md` (секция «Текущий контур 2026-09-17»).

## 3. Если не открывается

| Симптом | Что сделать |
|---------|-------------|
| `./scripts/open-site.sh` пишет про venv | `python3 -m venv .venv` и `.venv/bin/pip install -r requirements-dev.txt` |
| Превью старое | снова `./scripts/open-site.sh` |
| `docker: command not found` или broken symlink | установить Docker Desktop и перезапустить терминал |
| localhost:8080 не отвечает | `docker compose up -d`, подождать минуту, обновить страницу |
| WordPress просит установку | скрипт не дошёл до `core install` — запустите `./scripts/local-setup.sh` ещё раз |
| Тема «битая» | в админке сначала активируйте **Kadence**, потом **ИХНМ Kadence** |

Проверка модели (не открывает сайт, проверяет меню и подвал):

```bash
.venv/bin/pytest
```

## 4. Это ещё не ichnm.by

Пока вы смотрите **локальное** превью или **локальный** WordPress. Боевой домен не переключаем, пока руководство не примет сайт. Старый [ichnm.by](https://ichnm.by/) живёт параллельно.
