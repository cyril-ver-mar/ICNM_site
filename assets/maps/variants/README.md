# Minsk map variants

Open `preview/minsk-map-variants.html` and pick a look.

- `minsk-v1-admin.svg` — admin boundary (with eastern lobes)
- `minsk-v2-compact.svg` — compact land (east clipped)
- `minsk-v3-mkad.svg` — compact + MKAD stroke
- `minsk-v4-green.svg` — compact + parks / woods
- `minsk-v5-mkad-green.svg` — compact + MKAD + greens

Rebuild: `python3 scripts/build_minsk_map.py`
